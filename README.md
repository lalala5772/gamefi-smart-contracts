# Snowmen GameFi Smart Contracts

Solidity 기반의 GameFi 스마트 컨트랙트 프로젝트임. ERC-20 토큰과 ERC-1155 기반 게임 아이템을 활용하여 토큰 발행, 아이템 관리 및 판매, 티켓 구매 기능 구현.

## 주요 기능

- **게임 아이템 관리**: ERC-1155를 활용한 아이템 발행 및 수량 관리
- **메타데이터 연결**: IPFS CID를 활용한 아이템 메타데이터 URI 구성
- **게임 토큰 발행**: ERC-20 기반 토큰 발행 및 게임 점수의 토큰 변환
- **아이템 판매**: 설정된 가격과 보유 수량을 기준으로 게임 아이템 구매 처리
- **티켓 구매**: ETH를 이용한 게임 티켓 구매 및 발행 요청
- **접근 권한 관리**: 소유자 기반 관리자 기능 및 컨트랙트별 권한 제어

## 기술 스택

- **Language**: Solidity `^0.8.20` / `0.8.20`
- **Smart Contract Standards**: ERC-20, ERC-1155
- **Libraries**: OpenZeppelin Contracts
- **Metadata Storage Reference**: IPFS

## Smart Contracts

### 1. `SnowmenGame.sol`

ERC-1155 기반의 게임 아이템 관리 컨트랙트임.

- 권한이 있는 계정의 아이템 발행 기능 구현
- 아이템 메타데이터 CID 저장
- 토큰 ID와 폴더 ID를 활용한 메타데이터 URI 구성
- 관리자 계정의 권한 부여 및 회수
- 아이템 보유량 조회를 위한 ERC-1155 Supply 기능 활용

### 2. `SnowmenSales.sol`

게임 아이템 판매와 티켓 구매를 처리하는 컨트랙트임.

- ERC-1155 게임 아이템과 ERC-20 결제 토큰 연동
- 아이템별 판매 가격 설정
- 토큰 잔액, 승인 금액 및 판매 재고 검증
- 결제 토큰 전송 및 게임 아이템 지급
- ETH를 이용한 티켓 구매 및 티켓 발행 요청
- 컨트랙트에 보관된 ETH의 관리자 출금 기능 구현

### 3. `SnowmenToken.sol`

게임 내 결제 등에 활용할 수 있는 ERC-20 토큰 컨트랙트임.

- 토큰 이름: `Snowmen`
- 토큰 심볼: `SNOW`
- 초기 발행량: 1,000,000,000 SNOW
- 배포 시 초기 토큰을 배포자에게 발행하도록 구현

### 4. `GameScoreToken.sol`

게임 점수를 ERC-20 토큰으로 변환하는 별도 컨트랙트임.

- 토큰 이름: `GameScoreToken`
- 토큰 심볼: `GST`
- 점수와 토큰의 변환 비율 설정
- 점수 변환 요청에 따른 토큰 발행
- 관리자 전용 변환 비율 변경 기능 구현
- 점수 변환 내역을 이벤트로 기록

## 주요 동작 흐름

### 게임 아이템 구매

1. 관리자가 게임 아이템의 판매 가격을 설정함.
2. 판매 컨트랙트에 판매할 ERC-1155 아이템을 전송함.
3. 구매자가 ERC-20 토큰 사용을 승인함.
4. 구매 요청 시 결제 금액, 승인 금액 및 재고를 검증함.
5. 결제 토큰을 전송하고 구매자에게 아이템을 지급함.

### 티켓 구매

1. 구매자가 ETH와 함께 티켓 구매 함수를 호출함.
2. 판매 컨트랙트에서 게임 컨트랙트로 티켓 발행을 요청함.
3. 발행 요청이 성공하면 구매 이벤트를 기록함.

### 점수의 토큰 변환

1. 사용자가 변환할 점수를 전달함.
2. 설정된 변환 비율에 따라 발행할 토큰 수량을 계산함.
3. 사용자 점수를 기록하고 해당 수량의 ERC-20 토큰을 발행함.
